# Impeccable Review Brief — RITO Studio START

Perform a detector pass and a read-only visual critique. Do not apply changes automatically.

Evaluate:
- whether the site feels airy, tactile, elegant and contemporary;
- whether it is distinct from Hospitality and SaaS;
- hierarchy;
- typography;
- spacing;
- image selection and crop;
- service presentation;
- mobile composition;
- CTA clarity;
- visual accessibility;
- consistency of motion;
- generic AI-template signals.

Classify every observation:

```text
responsive bug
accessibility issue
genericity confirmed
subjective preference
identity element to preserve
large redesign to reject
technical issue
```

Do not recommend:
- a new palette;
- a new font system;
- gradients;
- glassmorphism;
- pill UI;
- custom cursor;
- card grids;
- broad redesign;
unless a concrete, evidenced problem requires discussion.

Return findings only. Each finding must identify location, evidence, impact and a minimal recommendation.
